# GAMMA intentionally has no pip-managed mandatory dependencies.
#
# It is designed to run inside an existing geometry/DAFoam environment, whose
# MPI, PETSc, NumPy, SciPy, CSDL, and DAFoam versions must remain under the
# environment administrator's control. Do not add active requirements here
# without verifying compatibility with that complete stack.
#
# Prerequisites used by the current mesh-motion drivers:
#   numpy
#   scipy
#   csdl_alpha
#   lsdo_function_spaces
#   jax
#   gmsh
#
# Additional prerequisites for cfd_mesh_dafoam_analysis.py are supplied by the
# sourced DAFoam environment:
#   dafoam
#   mpi4py
#   petsc4py
#
# Optional development/visualization tools:
#   pytest
#   meshio
#   pyvista
#
# Safe TSCC install (does not resolve or install dependencies):
#   python -m pip install --no-deps --no-build-isolation -e .
